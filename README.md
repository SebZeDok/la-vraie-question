# La vraie question

Page de présentation de mon offre de conseil aux dirigeants : six situations de transformation, les compétences mobilisées, mon parcours, et l'offre de CTO à temps partagé.

Une page HTML autonome (`index.html`), sans dépendance à installer.

## Voir la page

- En local : ouvrir `index.html` dans un navigateur.
- En ligne : https://sebzedok.github.io/la-vraie-question/ (GitHub Pages, branche `main`, dossier `/`).

## Contact

Le formulaire de contact ouvre la messagerie du visiteur avec un e-mail prérempli : son message, son nom, son rôle, la situation qui le concerne et, s'il le souhaite, un numéro de rappel. Chaque fiche propose un bouton « Parlons-en » qui mène au formulaire avec la situation déjà choisie. Aucun service tiers : rien n'est stocké en dehors de la messagerie du visiteur.

L'adresse de destination (sebastien [at] wavit.me) est assemblée dans le code au moment de l'envoi, pour ne pas apparaître en clair dans la page.

## Versions

Branche `evolutions` pour le travail en cours, `main` pour la version en ligne. Chaque mise en ligne fait l'objet d'une release (v1.0, v1.1, v1.2…).
