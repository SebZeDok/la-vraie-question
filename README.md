# La vraie question

Page de présentation de mon offre de conseil aux dirigeants : six situations de transformation, les compétences mobilisées, mon parcours, et l'offre de CTO à temps partagé.

Une page HTML autonome (`index.html`), sans dépendance à installer.

## Voir la page

- En local : ouvrir `index.html` dans un navigateur.
- En ligne : activer GitHub Pages (Settings → Pages → branche `main`, dossier `/`).

## Retours des lecteurs

Sur GitHub Pages, les avis sont conservés dans le navigateur du lecteur, qui peut les copier et me les envoyer avec le bouton « Copier mon avis ». L'enregistrement centralisé des retours ne fonctionne que dans la version publiée sur claude.ai.
